# API Scenario Forge

## 1. 목적과 기반 기술

`api-scenario-forge`는 MSW와 [`@msw-dev-tool`](https://msw-dev-tool-docs.vercel.app/)을 이용해 실행 중인 애플리케이션의 API 응답 시나리오를 조정하고, 그 결과를 애플리케이션에서 직접 검증하는 스킬입니다.

api 응답이 미구현된 상태거나 어렵거고 재현하기 힘든 조건도 실행 중에 만들 수 있습니다. 예를 들어 loading, error, empty, fallback, 비정상 응답을 실제 Browser나 Node 실행 경로에서 확인할 수 있습니다.

## 2. 적용 가능한 상황

- API 스펙상 가능한 응답이지만 실제 응답을 제공받기 어려운 경우
- API 구현이 완료되기 전 프론트엔드 화면을 개발해야 하는 경우
- 특정 상태코드, 네트워크 오류 또는 비정상 응답을 재현하기 어려운 경우
- 응답 본문을 자유롭게 구성해 여러 응답 케이스에 대한 결과를 확인해야 하는 경우
- 로딩, 재시도, fallback, error boundary를 실제 화면에서 검증해야 하는 경우

## 3. 동작 흐름

```mermaid
flowchart TD
    A[프로젝트와 MSW 설정 확인] --> B[Runtime detect]
    B -->|준비됨| C[API 시나리오(응답) 설정]
    B -->|준비되지 않음| D[Runtime init]
    D --> C
    C --> E[애플리케이션 기능 실행]
    E --> F[상태 확인]
    F --> G[Reset 및 상태 확인]
```

1. runtime이 준비되어 있으면 바로 API 시나리오 응답을 설정합니다.
2. runtime이 준비되지 않았으면 init을 진행한 뒤 API 시나리오 응답을 설정합니다.
3. 시나리오 설정 후 실제 애플리케이션 기능을 실행하고, 기대한 상태를 확인합니다.
4. 마지막에 clean up을 수행합니다.

다양한 시나리오를 병렬적으로 설정하고 확인 가능합니다.
Browser에서는 각 탭을 독립적인 scenario target으로 취급하고, Node에서는 각 프로세스와 PID를 독립적인 target으로 취급합니다. 서로 다른 시나리오를 같은 탭이나 Node 프로세스에 동시에 적용하지 않습니다.

## 4. 시나리오 예시

### 상품 목록과 상세 화면의 장애 상태 검증

상품 목록에서 상세 화면으로 이동하고 저장까지 수행하는 사용자 흐름을 기준으로 다음 상태를 검증할 수 있습니다.

| 검증 대상 | API 시나리오 | 기대 결과 |
|---|---|---|
| 목록 loading | 지연 응답 | skeleton UI를 원할 때 까지 표시 |
| 특수한 상품이 있는 목록 데이터 | 제휴사 특가 할인 상품 포함 | 특수 케이스 처리 결과 확인 |
| 상세 조회 실패 | `404` | not-found 화면과 재시도 버튼 |
| 저장 실패 | `503` 또는 network error | optimistic update 롤백과 오류 메시지 |
