# Skill Evaluation

## 사용자 흐름

1. 사용자가 `skill-evaluation`에 평가할 스킬을 지정합니다.
2. Codex가 기존 평가 계획을 불러옵니다. 기존 계획이 없으면 새 계획을 작성합니다.
3. Codex가 계획을 보여주면 사용자가 `평가 실행` 또는 `계획 수정`을 선택합니다.
4. 사용자가 수정을 선택하면 Codex가 계획 파일을 갱신해 다시 보여줍니다. 사용자가 `평가 실행`을 선택할 때까지 수정 요청과 계획 갱신을 반복합니다.
5. 사용자가 `평가 실행`을 선택한 뒤에 평가를 시작합니다.

## 흐름 예시

```text
사용자: $skill-evaluation api-scenario-forge
Codex: 기존 계획을 불러오거나 새 계획을 작성해 보여줍니다.
Codex: 평가를 실행할까요, 계획을 수정할까요?
사용자: 계획을 수정해 주세요.
Codex: 수정된 계획을 보여주고 다시 선택을 요청합니다.
사용자: 평가 실행
Codex: 평가를 시작합니다.
```
