# install-plannotator

`install-plannotator` 스킬은 [Plannotator](https://plannotator.ai/) 공식 설치 명령을 실행하고 Codex 연동을 설정합니다. 설치 후 별도 설정은 필요하지 않습니다.

Plannotator는 계획 모드에서 브라우저 UI로 작업 계획을 검토하고 AI에게 피드백을 보낼 수 있게 해줍니다. 실제 작업을 시작하기 전에 계획의 맥락과 항목을 조율할 때 사용할 수 있습니다.

직접 설치하려면 [공식 설치 안내](https://github.com/backnotprop/plannotator/blob/main/apps/codex/README.md)를 참고하세요.
