# Codex Complex Prompt

[Codex Complex Prompt](https://github.com/nayounsang/codex-complex-prompt)는 복잡한 작업 요청을 브라우저에서 검토하고, Codex의 피드백을 반영해 다듬은 뒤 실행하는 Codex CLI 플러그인입니다.

## 1. 해결하는 문제

> (수많은 채팅 기록...) 야 잠깐만 너 뭐해, 30분이나 걸려서 이렇게 하면 넘 불만족스러운데. 작업한거 날리고 내가 조건 더 줄테니 다시 해봐. 근데, 처음에 하자고 한게 뭐였지? 아 내가 이렇게 하라고 했다고? 무슨 소리야

복잡한 요청은 대화 중간에 조건을 보태거나 잘못된 결과를 고쳐 달라고 반복하다 보면, 처음 정한 목표와 세부 요구사항을 놓치기 쉽습니다.
요청을 풍부한 기능의 마크다운 에디터에서 직접 작성하고, 실행전 필요한 부분만 선택해 Codex에게 빠진 점이나 모호한 점을 검토하게 한 다음, 확인하고 실행할 수 있습니다.

## 2. 설치

먼저 이 marketplace에서 플러그인을 설치합니다.

```bash
codex plugin add codex-complex-prompt@younsang-codex-plugins
```

설치 스크립트를 실행해주세요. CLI 연동에는 Node.js 24 이상과 `npx`가 필요합니다.

```bash
npx @codex-complex-prompt/cli-bridge hook install
```

설치가 끝나면 Codex CLI를 재시작하세요. 새 hook을 검토하라는 안내가 나오면 `/hooks`에서 내용을 확인하고 신뢰 여부를 선택한 뒤, 새 대화에서 사용합니다.

## 3. 사용

Codex CLI에서 `$complex-prompt`를 호출해 요청 문서를 엽니다.

```text
$complex-prompt 결제 기능을 조사하고 구현 요청 문서를 작성해줘
```

- 요청 없이 `$complex-prompt`만 호출하면 빈 문서로 시작합니다.
- 일반 텍스트를 입력하면 그 내용을 초안으로 사용합니다.
- `.md` 또는 `.txt` 파일 경로를 입력하면 파일 내용을 초안으로 불러옵니다. **파일 원문은 작업하며 변경되지 않습니다.**

브라우저 편집기에서 요청을 직접 수정하거나 요구사항을 설명할 수 있습니다. 작성을 돕는 문서 템플릿도 제공합니다.

## 4. Codex 피드백을 반영하고 실행하기

> 기능 구현을 요청하기 전에 사용자 흐름과 예외 조건을 정리하거나, 리서치 범위와 결과 형식을 보완하거나, 문서 작성 조건을 빠짐없이 모으는 데 사용할 수 있습니다.

1. 원하는 부분만 선택해 `Send Feedback`으로 Codex에게 검토와 수정을 요청합니다. Codex가 피드백을 반영한 문서가 편집기에서 다시 열립니다.
2. 수정된 내용을 확인하고 필요한 부분을 더 다듬습니다. 원하는 결과가 될 때까지 피드백을 여러 번 주고받을 수 있습니다.
3. 요청이 준비되면 `Submit`을 눌러 문서의 내용을 Codex CLI에 전달하면 실행합니다.
